Cold Clear 2 opponent
====================

This game uses the real Cold Clear 2 search engine in a browser-local module
worker. The game is independent of TETR.IO, OSK, Cold Clear's authors, and the
community port's authors. None of those authors endorse this recreation.

The import-free WASM clock patch of instant retains its BSD-3-Clause license.
The accompanying complete upstream notices are preserved without alteration;
some entries refer to other components of s2-bot-lab that this game does not
bundle. No Triangle.js, replay importer, or S2 simulator JavaScript is included.

The Zen-specific adapter, worker protocol, reachability validation, and fallback
practice CPU are original code for this project. WASM suggestions are validated
through the game's own movement and kick rules before they are executed. The
opponent is labeled Cold Clear 2 only after accepting an actual WASM suggestion;
load failures, timeouts, or unreachable suggestions use the Practice CPU.
